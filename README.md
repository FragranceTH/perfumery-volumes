# Perfumery & Materials — sales page

Static site. Two files are served:

- `index.html` — the sales page (self-contained; covers embedded)
- `sample.pdf` — the six-page free excerpt

Do not add the paid volumes to this repository. They belong in the store.

## Deploy

GitHub: Settings -> Pages -> Deploy from a branch -> `main` / root.
Netlify: drag this folder onto app.netlify.com/drop.
